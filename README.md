EVENT MANAGEMENT SYSTEM
A full-stack application(MERN) for managing events and venues.

## Features
- **Event Management:** Create, view, and book events.
- **Venue Management:** Add and browse event venues with dimensions and cost.
- **Seat Booking:** Register or RSVP for events with real-time availability updates.
- **Responsive UI:** Modern design with hover effects and clean layouts.

## Tech Stack
- **Frontend:** React.js, React Router, Axios.
- **Backend:** Node.js, Express.js, MongoDB.

## Project Structure
- `event-frontend`: React application for the user interface.
- `event-backend`: Express server and database logic.

## Installation
1. Clone the repository.
2. Install dependencies for both folders using `npm install`.
3. Start the backend with `npm start` (port 5000).
4. Start the frontend with `npm start` (port 3000).
